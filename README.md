###**1. Предметная область**
Предметная область — учёт проживания студентов в общежитии, контроль заселения, выселения, мест и правил проживания.
В системе отслеживаются и хранятся данные по следующим аспектам:
**-	Студенты: ФИО, курс, паспортные данные, контактный телефон, статус проживания.**
**-	Комнаты: номер комнаты, этаж, тип, вместимость, текущее количество проживающих. **
**-	Заселения: дата заселения, номер комнаты, срок проживания, примечания.**
**-	Выселения: дата выселения, причина, акт сдачи комнаты.**
**-	Нарушения и взыскания: тип нарушения, применённые меры.**
###**2. Цели системы:**
-	автоматизировать учёт проживающих студентов и контроль свободных мест;
-	вести историю заселений/выселений и формировать приказы/акты;
-	отслеживать нарушения и фиксировать меры воздействия;
**Польза для пользователей:**
-	исключение ручного дублирования данных и снижение ошибок;
-	быстрый поиск информации о студенте, комнате, статусе оплаты;
-	оперативная аналитика по заполняемости, задолженностям, нарушениям.
###**3. Пользователи системы и их роли**
####**1.	Заведующий (комендант) общежития**
-	Регистрация студентов в базу данных
-	Фиксирует нарушения и принимает меры
####**2.	Студенты**
-	Проверка на наличие мест в общежитии
-	
-	Просмотр личных данных
###**4. Список основных функций системы**
-	Регистрация и редактирование данных о студентах: добавление, изменение, поиск по ФИО, группе, статусу.
-	Управление комнатами: учёт вместимости, статусов.
-	Оформление заселения/выселения: создание записей с датами, основаниями, актами.
-	Учёт нарушений: регистрация, назначение мер.
-	Поиск и фильтрация: по студенту, комнате, периоду, статусу, задолженности.
